# LSP — Levelup Sports Partner · démo du site

Démo fonctionnelle (une seule page HTML autonome) du site de l'agence.

- Site public : `index.html`
- Back-office : ajouter `#admin` à l'adresse du site
- Données fictives, enregistrées uniquement dans le navigateur de chaque visiteur (localStorage)

Les identifiants de démo sont fictifs. Ce n'est pas la version de production
(prévue sur Cloudflare Workers + D1, avec contrôle d'accès côté serveur).
